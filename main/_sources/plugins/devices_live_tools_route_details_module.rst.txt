.. Title

cisco.meraki.devices_live_tools_route_details module -- Resource module for devices \_live \_tools \_route \_details
++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++

.. Collection note

.. note::
    This module is part of the `cisco.meraki collection <https://galaxy.ansible.com/ui/repo/published/cisco/meraki/>`_ (version 2.26.0).

    It is not included in ``ansible-core``.
    To check whether it is installed, run :code:`ansible-galaxy collection list`.

    To install it, use: :code:`ansible\-galaxy collection install cisco.meraki`.
    You need further requirements to be able to use this module,
    see :ref:`Requirements <ansible_collections.cisco.meraki.devices_live_tools_route_details_module_requirements>` for details.

    To use it in a playbook, specify: :code:`cisco.meraki.devices_live_tools_route_details`.

.. rst-class:: ansible-version-added

New in cisco.meraki 1.0.0

Synopsis
--------

.. Description

- Manage operation create of the resource devices \_live \_tools \_route \_details.
- Enqueue a live tool job to fetch route details from a device.

.. note::
    This module has a corresponding :ref:`action plugin <action_plugins>`.

.. Requirements

.. _ansible_collections.cisco.meraki.devices_live_tools_route_details_module_requirements:

Requirements
------------
The below requirements are needed on the host that executes this module.

- meraki \>= 2.4.9
- python \>= 3.5

.. Notes

Notes
-----

.. note::
   - SDK Method used are devices.Devices.create\_device\_live\_tools\_route\_detail,
   - Paths used are post /devices/{serial}/liveTools/route/details,
   - Does not support :literal:`check\_mode`
   - The plugin runs on the control node and does not use any ansible connection plugins, but instead the embedded connection manager
   - from Cisco Dashboard API Python(SDK)
   - The parameters starting with meraki\_ are used by the Cisco Meraki Python SDK to establish the connection
